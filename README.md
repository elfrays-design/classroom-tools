# 별이와 송이의 수업도구 상자 v1.5

교사가 학생 명단을 한 번 등록해 **발표 레이스 · 랜덤 발표자 · 모둠 편성 · 수업 타이머 · 자리 배치 · 참여 기록**을 사용할 수 있는 웹앱입니다.

## 중요한 개인정보 안내
- 서비스에는 계정, 서버, 데이터베이스, 추적 도구 및 외부 라이브러리가 없습니다.
- 학생 이름과 기록은 **접속한 브라우저의 IndexedDB에 저장**됩니다. IndexedDB를 사용할 수 없는 환경에서는 `localStorage`를 시도합니다.
- 학생 이름/기록은 GitHub에 업로드되지 않습니다. GitHub에는 이 소스코드만 게시합니다.
- 브라우저 데이터 삭제, 시크릿 모드, PC 변경, 브라우저 프로필 변경 시 기록이 사라질 수 있습니다. **'백업'으로 JSON 파일을 정기적으로 내려받아 보관**하세요.
- 백업 JSON과 CSV에도 학생 이름이 포함됩니다. 학교 개인정보 처리 규정에 따라 보관·공유·파기하세요.
- 같은 PC를 여러 사람이 함께 사용하는 경우, 동일한 브라우저 프로필을 쓰는 다른 사람이 저장된 명단을 볼 수 있습니다.
- **학교의 공식 개인정보 처리 적정성 검토를 거친 서비스가 아닙니다.** 실제 학생 실명 사용 전에 해당 기관의 개인정보보호·정보보안 지침을 검토하세요.

## GitHub Pages로 무료 배포하기 (초보자용)
1. [GitHub](https://github.com/)에서 계정에 로그인합니다.
2. 우측 상단 `+` → `New repository`에서 저장소를 만듭니다. 예: `classroom-tools`. 공개 저장소(`Public`)로 생성합니다.
3. `Add file` → `Upload files`를 클릭합니다.
4. 이 ZIP 파일의 **압축을 푼 뒤**, `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` 및 `.nojekyll` 파일을 저장소 **최상위 폴더**에 올립니다. ZIP 파일 자체만 올리면 웹사이트는 실행되지 않습니다.
5. `Commit changes`를 누릅니다.
6. 저장소의 `Settings` → `Pages` → `Build and deployment`에서 `Source: Deploy from a branch`를 선택합니다.
7. `Branch: main`, 폴더: `/(root)`를 선택하고 `Save`를 누릅니다.
8. 게시가 완료되면 `https://깃허브아이디.github.io/classroom-tools/` 주소로 접속할 수 있습니다.

※ 저장소 이름은 본인이 만든 이름을 사용하세요. 다른 이름이라면 웹주소도 달라집니다.

## 로컬에서 시험하기
이 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8000
```

웹브라우저에서 `http://localhost:8000/`에 접속하면 됩니다. PWA 설치와 서비스 워커를 시험할 때는 `file://` 대신 localhost 또는 HTTPS를 사용하세요.

## 사용방법
1. **학급 명단 관리**에서 학급을 만들고 학생 이름을 등록합니다.
2. 발표 레이스, 랜덤 발표자, 모둠 편성, 자리 배치, 참여 기록을 사용합니다.
3. 기록은 브라우저에 자동 저장됩니다.
4. 우측 상단 **백업**으로 JSON 파일을 저장하고, 필요 시 **복원**으로 불러옵니다.
5. CSV는 Excel 등에서 열 수 있습니다.

## 구조
- HTML/CSS/순수 JavaScript: 별도 설치나 유료 API가 필요 없습니다.
- IndexedDB: 현재 기기 브라우저에 학급 및 활동 기록 보관.
- Service Worker/PWA: 첫 온라인 방문 후 파일 캐싱; 네트워크가 끊겨도 기본 도구를 사용할 수 있도록 설계.
- GitHub Pages: 정적 파일 호스팅. 실제 게시와 HTTPS 접속 이후 PWA 설치 기능 이용 가능.

## 알려진 제한
- PC·브라우저 프로필 간 자동 동기화는 제공하지 않습니다.
- 발표 레이스는 시각적 추첨 효과이며 학생별 평가점수 계산 기능은 없습니다.
- IndexedDB 저장은 용량·보존이 브라우저 정책의 영향을 받습니다.
- 클라우드 저장, AI 기능, 교사 계정, 학생별 세부 서술 기록은 포함하지 않았습니다.
- 기능 업데이트 시 `sw.js`의 `CACHE_NAME` 버전을 변경해야 설치형 앱에 변경사항이 적용됩니다.

## 자리 배치 (v1.5)

- 30명 학급 기준 기본 배치는 **가로 5열 × 세로 6줄**입니다.
- 가로(3~8열)·세로(3~12줄)를 독립 설정하며, 설정은 학급별로 브라우저에 저장됩니다.
- 좌석 수보다 학생 수가 많으면 누락 방지를 위해 세로 줄이 자동으로 확장됩니다. 남는 자리는 빈 자리로 표시됩니다.
- 두 학생 자리 클릭으로 자리 교환 가능. **배치 복사** 시 줄별로 복사됩니다.
- 이전 버전 학급 데이터와 백업 파일을 열어도 기존 학생과 배치는 유지됩니다.

- 랜덤 발표자: 큰 원통형 추첨기에서 이름이 3초 동안 움직인 뒤 한 명 선택
### 발표 레이스 (v1.6)
토끼·강아지·고양이 등 동물 캐릭터가 달린 후, 1~3등 시상대와 전체 순위 화면을 표시합니다. 순위는 무작위 발표 순서이며 학생 성취도 평가가 아닙니다. 결과 복사·인쇄·다시 달리기를 지원합니다.

### 화면 테마 및 캐릭터 이미지 (v1.7)
- 홈 화면 캐릭터 이미지를 사용자 제공 별이·송이 이미지로 교체했습니다.
- 상단에서 `초등 맞춤 귀여운 화면`과 `중등 맞춤 깔끔한 화면` 중 하나를 선택해 사용할 수 있습니다.
- 화면 선택 값은 사용하는 브라우저에 저장됩니다.


## v1.8 — 우리 반 전자칠판
- 기존 수업도구상자에 「우리 반 전자칠판」 메뉴 추가

- 동일 화면에서 편집 후 `전자칠판 크게 보기` 버튼으로 발표용 화면 표시, 다시 편집 가능
- 현재 시각 및 현재/다음 교시 자동 표시(입력한 시작/종료 시각 기준)
- 기존 학생 명단과 마찬가지로 학급별 브라우저 저장 및 전체 JSON 백업/복원에 포함
- 다른 기기에는 자동 동기화되지 않음. 급식·날씨 API 연동 없음

### 채점 줄서기 v1.9
학생 이름 터치로 대기 등록(중복 방지), 대기 번호 표시, 선생님의 다음 학생 호출·채점 완료·호출 취소, 대기 취소, 초기화, 순서 복사 및 학생용 크게 보기를 지원합니다. 학급별 브라우저 저장과 JSON 백업·복원에 포함되며 독립 PC간 자동 동기화는 지원하지 않습니다.

### 급식 줄서기 — 인형뽑기 (v1.10)
- 기존 학생 명단을 이용한 학급별 급식 순서 정하기. CSS 인형뽑기 기계의 집게가 약 3.2초 움직인 뒤 결과 발표.
- ① 한 명 뽑기(중복 없이 번호 부여) ② 남은 학생 전체 순서 한 번에 뽑기, 결과 목록과 복사·초기화 지원.
- 학급별 브라우저 저장 및 JSON 전체 백업/복원 대상. 다른 PC/독립 전자칠판과 실시간 연동하지 않음.

### v1.10.1 — 급식 인형뽑기 그림 일치 수정
- 학생 ID별 동물 이모지를 고정하여 인형 이름표, 집게에 잡힌 인형, 결과 창, 급식 순서표가 동일하도록 개선.
- 집게에 잡힌 인형에 학생 이름을 함께 표시하고, 집게가 닿는 위치에 당첨 인형을 배치.

### 급식 줄서기 가챠통 (v1.11)
- 오류가 잦았던 집게식 인형뽑기를 삭제하고, 동그란 가챠통에서 캡슐이 섞여 나오는 방식으로 교체했습니다.
- 캡슐에서는 뽑힌 뒤에 학생 이름을 공개하므로 이름/동물 불일치가 발생하지 않습니다.
- 한 명씩 뽑기(약 3.1초), 남은 학생 전체 순서 뽑기, 중복 방지, 순서표 복사·초기화, 학급별 브라우저 저장과 기존 백업·복원 유지.

## v1.12 — 알림장 칠판
- 기존 '우리 반 전자칠판'과 별도인 「알림장 칠판」 도구 추가.
- 제목·날짜·숙제·준비물·전달사항·오늘의 한마디를 입력하면 학급별로 자동 저장.
- 초기 예시: 수학 익힘책 24쪽 풀기 / 색연필, 풀, 가위 / 내일 체육복 입고 오기 / 오늘도 즐겁게 공부해요!.
- 기본 색상 초록(green), 글씨 크게(large); 검정·남색, 보통·아주 크게, 줄노트 배경 선택 가능.
- 학생용 칠판 크게 보기 및 편집 전환, 내용 지우기(학생 기록은 유지), 기존 JSON 전체 백업·복원 포함.
- 다른 PC·전자칠판과는 자동 동기화되지 않음.

## v1.13 — 마니또·비밀친구
- 기존 학급 명단을 이용해 자기 자신을 제외한 일대일 비밀친구 배정. 2명 이상 지원하며 모두가 한 명을 주고받는 원형 순열.
- 활동(마니또·비밀친구) 선택, 기본 배려 미션 10개, 미션 40개까지 직접 작성, 개인별 미션 무작위 배정.
- 학생이 이름을 선택하고 비밀카드를 열면 12초 후 자동 가림, 수동 가림·미션 완료·다시 뽑기.
- 결과·미션은 로컬 저장 및 JSON 백업/복원. 계정·개별 인증 기능이 없으므로 전자칠판 공개 화면에서 열지 말아야 함.

## v1.16 발표 레이스 연동 발표 스톱워치
- 발표 레이스 결과에서 「1등부터 발표 시작」을 눌러 무작위 순위를 발표 순서로 고정합니다. 독립 메뉴 「발표 스톱워치」에서도 저장된 레이스 결과 불러오기 지원.
- 기본 발표 제한시간 2분. 5초~60분 사이 분/초 조정 가능, 남은 시간과 경과 시간·다음 학생·순위 목록 표시.
- 시작·일시정지·종료·다음 발표자 기능. 제한시간 만료 시 알림음, 다음 학생은 수동 이동.
- 학급별 순서·진행·완료 기록은 기존 로컬 저장 및 JSON 백업·복원에 포함. 다른 도구로 이동할 때 측정 중이라면 일시정지.
- 레이스를 새로 진행해도 기존 발표 순서는 자동 변경하지 않고, 새 순위를 가져올 때 완료 기록 초기화 여부를 확인.

## v1.18 — 채점 줄서기 교사용 조작 개선
- 학생용 크게 보기에서도 화면 아래 교사 조작 바를 항상 표시합니다. 화면을 닫지 않고 학생 호출·채점 완료·호출 취소를 진행합니다.
- 「채점 완료 + 다음 호출」 원클릭 버튼: 현재 학생을 완료 기록에 넣고 다음 대기 학생을 바로 호출합니다. 마지막 학생은 완료만 처리합니다.
- 버튼은 현재 학생/대기 상태에 따라 비활성화되고, 교사 바에 현재 학생과 다음 학생을 표시합니다.
- 기존 채점 데이터·학생 명단·브라우저 저장/백업 방식 그대로 유지.

- 모둠 재편성 시 기존 배정을 덮어쓰기 전에 확인하고, 이전 이력은 유지합니다.
